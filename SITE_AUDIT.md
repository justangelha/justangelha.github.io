## Проверки и открытые пункты

- **GitHub Pages до правок.** Все 21 URL прежней карты сайта ответили HTTP 200. HTTP перенаправлял на HTTPS с кодом 301. Все 22 скачанных файла совпали с исходной ревизией. Неизвестный путь вернул фирменную страницу с кодом 404. `article.html?id=…` отдаёт общий шаблон с HTTP 200.
- **Локальная копия.** Проверены синтаксис JavaScript, XML, 41 внутренний URL и ресурсов, девять типов якорей и метаданные всех 16 статей. В Chrome проверили 27 адресов на каждой из ширин 320, 375, 390, 768 и 1440 px. Горизонтального переполнения, ошибок JS и загрузки ресурсов не было. Прошли навигация, каталог, фильтры, поиск и очистка, пустая выдача, добавление и удаление избранного, тема, недоступное и повреждённое localStorage, мобильное меню и Escape, неизвестный ID и UTM. Сервер предпросмотра вернул 28 ответов HTTP 200 и фирменный HTTP 404 для вложенного несуществующего пути. В предпросмотре Метрика отключена.
- **Ресурсы и скорость.** Восемь SVG весят суммарно 11 295 байт. Системные шрифты, отложенные скрипты и lazy loading проверены. В локальном Chrome с подменой ответа Метрики сделали по три загрузки главной, каталога и первой статьи на 390 и 1440 px до и после. Медиана CLS каталога на 390 px снизилась с 0,104 до 0, на 1440 px с 0,112 до 0. После правок CLS равен 0 во всех 18 загрузках. Медианы LCP колебались в пределах 80–144 мс до правок и 80–116 мс после, без устойчивого улучшения на всех страницах. Сняли выборочное покрытие CSS и JS в пользовательских сценариях. Lighthouse и полевой INP не измерялись.
- **Внешние ресурсы.** MuseScore Studio открылся по HTTPS с перенаправлением на `/en`. MuseScore.com ответил автоматическому клиенту кодом 403, доступность в обычном браузере остаётся открытой. Скрипт Метрики ответил 200. Получение новых просмотров, внешних кликов и цели в кабинете отдельно не подтверждены.
- **Ограничение GitHub Pages.** Для карточек статей у платформ без JS потребуется отдельный статический HTML на статью с сохранением прежних ссылок как совместимых входов. Такой переход меняет предпочитаемые адреса и требует согласования. Текущая локальная версия сохраняет существующие URL.
- **Обновление каталога.** При добавлении публикации нужно синхронно обновить `js/data.js`, список ссылок в `catalog.html` и `sitemap.xml`.
- **Проверка в кабинете.** После одного перехода на опубликованную статью с тестовой UTM-меткой можно открыть «Источники → Метки UTM» в счётчике и сверить источник.
